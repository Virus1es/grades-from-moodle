Мои оценки

Войдите под своей учётной записью Moodle, чтобы увидеть итоговые оценки с названиями дисциплин вместо числовых идентификаторов.

Данные отправляются напрямую на указанный Moodle по HTTPS. Пароль и токен не сохраняются в хранилище браузера.

Результаты обучения

Учебный проект · Moodle REST API · Без сторонних библиотек. Проверяйте адрес страницы перед вводом пароля. Не размещайте пароли и токены в публичном репозитории.
